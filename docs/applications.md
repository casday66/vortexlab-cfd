# Applications

This simulator can support conceptual studies in several fields:

- civil engineering: wind and water flow around bridge piers, building edges, and coastal structures
- mechanical engineering: wake behavior around bluff bodies and ducts
- environmental engineering: channel-flow visualization and obstacle-induced recirculation
- marine/coastal systems: simplified current interaction with piles, breakwaters, and submerged bodies
- instrumentation: vortex flow meter concepts
- STEM education: Reynolds number, viscosity, wake instability, and vortex shedding

The simulator is intentionally transparent. Parameters and assumptions are exposed so the user can connect numerical behavior with physical reasoning.
